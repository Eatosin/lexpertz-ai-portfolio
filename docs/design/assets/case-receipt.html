What this proves

The circuit can assemble an answer and defend it against the retrieved passages. When faithfulness drops below the gate, it retries with a narrower retrieval window rather than guessing.

  • Every claim traces to a cited passage.
  • Refusal is a first-class outcome, not an error.
  • Tool contracts are shared between IDE and backend via MCP.

What it does not prove

Accuracy is measured on the evaluation set, not on your corpus. A missing document still yields a refusal — which is honest, but it is not an answer.

  • No claim about unseen filing formats.
  • No guarantee against adversarial documents.
  • No live customer metric is published here.
